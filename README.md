# Learn Chinese

A mobile-first Mandarin learning web app (installable PWA, works offline) to learn **all HSK
vocabulary** with spaced repetition and to **speak** in three real situations: travelling in mainland
China, meeting and visiting a partner's Chinese family, and working with Chinese colleagues and clients.

Correctness of the language content comes first. Every word, phrase, tone, etiquette rule and travel fact
comes from a source that was read and recorded next to the item; pinyin is checked word by word against
a dictionary; anything that could not be verified is **not shown** and is listed in
[docs/UNVERIFIED.md](docs/UNVERIFIED.md). Research and decisions: [docs/RESEARCH.md](docs/RESEARCH.md);
every source with licence and access date: [docs/SOURCES.md](docs/SOURCES.md); data contract:
[docs/DATA.md](docs/DATA.md).

| | |
| --- | --- |
| Vocabulary | 12,366 words: the official **2025 HSK exam syllabus** (CLEC; the exam from 13 Dec 2026), the GF 0025-2021 standard and HSK 2.0 (2012 revision), every word tagged with its level in all three |
| Dictionary check | every HSK word's pinyin compared with CC-CEDICT; 199 differences resolved one by one in [data/hsk/resolutions.json](data/hsk/resolutions.json) (incl. three typos in the official 2025 list) |
| Audio | 7,359 native-speaker recordings (audio-cmn), used only where the file name fixes the reading; otherwise the device's Chinese voice, labelled as synthetic ([pre-generated neural audio](#audio) is one command away) |
| Speaking | scenes for travel, family and work with sourced phrases (each linked to the HSK words in it), usage notes, etiquette tips and practice dialogues; kinship chart; record yourself and compare with the model on speak cards; tone trainer with pinyin chart, drills and an experimental pitch contour |
| Learning | FSRS-6 spaced repetition (ts-fsrs) with retention Lighter 0.85 / Balanced 0.90 / Intensive 0.95, card types Chinese → English (characters, pinyin optional) → English → Chinese → phrase, with Listen as an optional extra, new words paused while reviews are overdue, star (hard) and skip (known), progress per level, streak, daily goal, study time, time to the next level |

## Layout

```
app/                     the web app = the Vercel project (Root Directory "app")
  index.html, styles.css, manifest.webmanifest, sw.js (offline), icons/
  src/main.js            boot + hash router; views in src/views/<name>.js
  src/lib/               pure logic, unit tested: pinyin, srs (FSRS), queue, marks, stats, settings, search, storage, pitch, tonedrill
  src/recorder.js        microphone recording for record-and-compare (stays on the device)
  src/vendor/ts-fsrs.mjs ts-fsrs 5.4.2 (MIT), vendored unmodified
  data/                  generated, committed: manifest, words-<level>.json, content.json, tones.json
  audio/s, audio/w       recordings (generated by the build from audio-cmn)
  api/                   Vercel functions for optional sign-in and sync (see docs/SYNC.md)
  scripts/dev-server.mjs local server (static files + api/, same headers as vercel.json)
  tests/                 node:test suites for the app (sync, API, pitch, tone drills, service worker)
data/                    canonical JSON (edit and review here): hsk/, situations/, reference/, generated/, sources/
docs/                    RESEARCH.md, SOURCES.md, UNVERIFIED.md (generated), DATA.md, SYNC.md
scripts/                 fetch-sources, import-hsk, ingest-research, build-app-data, build-sw, validate, generate-tts,
                         simulate-plan, vendor-ts-fsrs
.github/workflows/       check.yml: tests, validator and precache check on every push
tests/                   node:test suites for the pipeline and the pure logic
raw/                     upstream downloads (gitignored; pinned in data/sources.lock.json)
```

No framework and no build step: plain HTML, CSS and native ES modules, like the reference project
(Inburgering flashcards). The only runtime dependency is the vendored ts-fsrs module.

## Run locally

```bash
npm run dev
```

That serves the app and its API on http://127.0.0.1:4176 (`node app/scripts/dev-server.mjs`). Any static
server works for everything except sign-in: `python3 -m http.server -d app 8080`. Sign-in also needs the
accounts service of the reference project running locally (see [docs/SYNC.md](docs/SYNC.md)).

## Test and validate

```bash
npm test
```

```bash
npm run validate
```

`npm test` runs the pipeline and logic suites (`tests/`) and the app suites (`app/tests/`); GitHub Actions
runs the tests, the validator and `node scripts/build-sw.mjs --check` on every push. The validator
fails on invalid pinyin syllables, tone-mark errors, duplicate ids, words with no audio, phrases with
characters outside the simplified character set, entries missing provenance, unresolved disagreements
with CC-CEDICT, and phrases that fail the word-by-word dictionary check; it rewrites
`docs/UNVERIFIED.md`.

## Regenerate the data

```bash
npm run fetch
```

```bash
npm run import
```

```bash
npm run build
```

1. `scripts/fetch-sources.mjs` downloads every upstream source at a pinned version into `raw/` and
   checks its SHA-256 (`data/sources.lock.json`): CC-CEDICT, the official 2025 syllabus PDF, the 2021 and
   HSK 2.0 lists, wordfreq, audio-cmn. Needs `curl`, `git`, `unzip`, `tar` and `pdftotext` (poppler-utils).
2. `scripts/import-hsk.mjs` parses the syllabus PDF and merges the three lists into `data/hsk/`, checks
   every word against CC-CEDICT, applies the recorded decisions and lists new disagreements as `pending`
   (the validator then fails until each has a decision with a source).
3. `scripts/build-app-data.mjs` writes `app/data/`, copies the recordings into `app/audio/` and refreshes
   the committed CC-CEDICT subset (`data/sources/cedict-subset.json`, enough to validate offline and in CI).
4. `scripts/build-sw.mjs` (also part of `npm run build`) updates the service worker's list of app files.
   Run `npm run build` after any change in `app/` or `data/`, before committing; CI fails otherwise.

The FSRS scheduler is vendored: `node scripts/vendor-ts-fsrs.mjs --check` confirms that
`app/src/vendor/ts-fsrs.mjs` is the published ts-fsrs 5.4.2 file (npm integrity checked); without
`--check` it re-creates it.

Phrases, kinship terms, grammar, pitfalls and travel facts live in `data/situations/` and
`data/reference/`; edit them there (they were imported once from the research with
`scripts/ingest-research.mjs`, which also drops notes about the research process from the texts the app
shows). Only items with `"status": "verified"` reach the app. Practice dialogues
(`data/generated/dialogues.json`) only arrange verified phrases; they are marked as AI-assembled and listed
in [docs/AI-CONTENT.md](docs/AI-CONTENT.md) for review. To update CC-CEDICT,
change its pin in `scripts/fetch-sources.mjs`, fetch with `--force`, re-import and review the diff.

## Re-check the facts that change

Visa rules, mobile payment, train ticketing and similar facts live in `data/reference/facts.json`, each
with `checked_on` and a `recheck_url` (the official page). Before a trip:

1. Open each `recheck_url` (the app's *Travel facts* page links them too) and compare.
2. Edit `answer`, `checked_on` and `sources` (with the new access date) in `data/reference/facts.json`.
3. `npm run build && npm run validate`, commit.

All 31 facts were confirmed or corrected by independent checks on 2026-11-02 (20 of them by a second check with fresh web searches and a skeptic). Many official Chinese
and Dutch government pages could not be opened from the research environment and were read through
search-result summaries (each source says so), so open the `recheck_url` before relying on a fact. A fact
that fails a later check gets `"status": "unverified"`: the app then lists only its question and official
page under *Not double-checked yet*, never the answer.

As checked on 2026-11-02: the unilateral visa-free policy for Dutch passports (30 days) runs until
24:00 Beijing time on 31 Dec 2026 and no extension had been announced; check the Chinese embassy's
notices before booking a trip in 2027. *.vercel.app addresses may be blocked or slow in mainland China:
install the app (or open it once) before you travel, after that it works offline.

## Audio

Recordings come from [audio-cmn](https://github.com/hugolpz/audio-cmn): syllables by Chen Wang (CC BY-SA
3.0), words by Yue Tan (Shtooka, CC BY-SA). A recording is used only where its name fixes the reading: one syllable named by
its pinyin, or a word whose characters have exactly one CC-CEDICT reading. Everything else is spoken by
the device's Chinese voice, which can misread characters with several readings, so the app labels it.

To replace the device voice with pre-generated neural audio (Google Cloud Text-to-Speech, with the
reading forced through SSML pinyin where a character has several readings):

```bash
node scripts/generate-tts.mjs --dry-run
```

```bash
GOOGLE_TTS_API_KEY=your-key node scripts/generate-tts.mjs
```

The dry run counts the clips and billed characters for all words without a recording plus every phrase,
kinship term and grammar example: on 2026-11-02 that was 5,894 clips and 26,887 billed characters with the
WaveNet voice, about US$0.11 at list price and US$0 inside the monthly free tier of 4 million characters. Billing must be enabled on the Google Cloud project; the
key is only read from the environment. Behind a proxy add `NODE_USE_ENV_PROXY=1`. The clips go to
`app/audio/g/` and their index to `data/audio/tts-index.json`; `npm run build` then uses a clip wherever no
recording exists and its pinyin still matches (the app labels it "Generated voice (synthetic)"). Listen to
a sample before committing.

## Deploy on Vercel

The app is a static site plus small Vercel functions; there is no build command.

1. On vercel.com: **Add New → Project**, import `OOC7117/learn-chinese`, set **Root Directory** to `app`,
   Framework Preset **Other**, leave Build Command and Output Directory empty. Deploy.
2. Every push to the repository now deploys: production for the production branch, a preview for other
   branches. The repository's only (and default) branch is `claude/chinese-learning-repo-vaelpt`, so Vercel
   takes it as the production branch; to use `main` instead, create `main` from it on GitHub, make it the
   default branch and set it under Settings → Git in Vercel.
3. Optional, for sign-in and sync: add **Upstash Redis** from the Marketplace (Storage tab) and set
   `ACCOUNTS_URL` and `ACCOUNTS_SERVICE_KEY` to the values of the existing accounts service; details and
   the accounts project's `ACCOUNTS_APP_URLS` entry in [docs/SYNC.md](docs/SYNC.md). Without them the app
   works fully on the device and says "Sign-in is not available right now".

`app/vercel.json` sets strict security headers (CSP without third-party hosts, no framing,
`microphone=(self)` for the record-and-compare feature) and the caching of data, audio and the service
worker. Keep the deployment below 15,000 files and 100 MB (today: 7,441 files, 47.3 MB).
